SQL PART 8 — SUBQUERIES
========================

A subquery is a query inside another query.

1. Highest marks student:

SELECT *
FROM students
WHERE marks = (
    SELECT MAX(marks)
    FROM students
);

OUTPUT:
Priya 91

2. Students above average:

SELECT *
FROM students
WHERE marks > (
    SELECT AVG(marks)
    FROM students
);

OUTPUT:
Priya 91
Rahul 85

3. Subquery with IN:

SELECT *
FROM students
WHERE city IN (
    SELECT city
    FROM students
    WHERE marks > 80
);

4. Correlated subquery:

SELECT *
FROM students s
WHERE marks > (
    SELECT AVG(s2.marks)
    FROM students s2
    WHERE s2.city = s.city
);

This compares a student with the average marks
of their own city.
