SQL PART 13 — STORED FUNCTIONS
===============================

A function returns a value.

Example:

DELIMITER //

CREATE FUNCTION getGrade(mark INT)
RETURNS VARCHAR(10)
DETERMINISTIC
BEGIN
    DECLARE grade VARCHAR(10);

    IF mark >= 90 THEN
        SET grade = 'A';
    ELSEIF mark >= 80 THEN
        SET grade = 'B';
    ELSEIF mark >= 70 THEN
        SET grade = 'C';
    ELSEIF mark >= 60 THEN
        SET grade = 'D';
    ELSE
        SET grade = 'F';
    END IF;

    RETURN grade;
END //

DELIMITER ;

Use:

SELECT
    name,
    marks,
    getGrade(marks) AS grade
FROM students;

OUTPUT:
Rahul 85 B
Aman 72 C
Priya 91 A
Neha 68 D
Rohit 78 C

PROCEDURE vs FUNCTION:
Procedure is called with CALL.
Function returns a value and can be used in expressions.
