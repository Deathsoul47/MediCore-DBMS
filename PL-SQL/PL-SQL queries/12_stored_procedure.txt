SQL PART 12 — STORED PROCEDURES
=================================

A stored procedure is saved SQL logic that can be called later.

1. Basic procedure:

DELIMITER //

CREATE PROCEDURE getStudents()
BEGIN
    SELECT *
    FROM students;
END //

DELIMITER ;

CALL getStudents();

OUTPUT:
Returns all rows from students.

2. Procedure with parameter:

DELIMITER //

CREATE PROCEDURE getStudentById(IN id INT)
BEGIN
    SELECT *
    FROM students
    WHERE student_id = id;
END //

DELIMITER ;

CALL getStudentById(2);

OUTPUT:
Aman 21 Male Bhopal 72

3. IN parameter:
Input to procedure.

4. OUT parameter:
Can return a value through a variable.

Example:

DELIMITER //

CREATE PROCEDURE countStudents(OUT total INT)
BEGIN
    SELECT COUNT(*) INTO total
    FROM students;
END //

DELIMITER ;

CALL countStudents(@total);
SELECT @total;
