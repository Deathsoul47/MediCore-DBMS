SQL PART 3 — ORDER BY, LIMIT & DISTINCT
=======================================

ORDER BY ASC:

SELECT *
FROM students
ORDER BY marks ASC;

ORDER BY DESC:

SELECT *
FROM students
ORDER BY marks DESC;

TOP 3:

SELECT *
FROM students
ORDER BY marks DESC
LIMIT 3;

DISTINCT:

SELECT DISTINCT city
FROM students;

---------------
Top 3:
Priya 91
Rahul 85
Rohit 78

DISTINCT city:
