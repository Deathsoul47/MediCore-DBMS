SQL PART 20 — ALTER, DELETE, TRUNCATE, DROP
=============================================

1. ADD COLUMN

ALTER TABLE students
ADD email VARCHAR(100);

2. MODIFY COLUMN

ALTER TABLE students
MODIFY name VARCHAR(100);

3. RENAME COLUMN

ALTER TABLE students
RENAME COLUMN name TO student_name;

4. DROP COLUMN

ALTER TABLE students
DROP COLUMN email;

5. DELETE

DELETE FROM students
WHERE student_id = 1;

Deletes selected rows.

6. TRUNCATE

TRUNCATE TABLE students;

Deletes all rows but keeps the table structure.

7. DROP

DROP TABLE students;

Deletes the table itself.

SUMMARY:
DELETE     -> rows
TRUNCATE   -> all rows
DROP       -> table + data + structure
