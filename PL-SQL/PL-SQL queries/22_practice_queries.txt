SQL PART 22 — PRACTICE QUERIES
===============================

Use the students table.

1. Find students with marks above 80.

2. Find the student with the highest marks.

3. Find the average marks.

4. Find city-wise average marks.

5. Find cities having average marks above 75.

6. Find the second-highest marks.

7. Find the top 2 students from each city.

8. Rank students by marks.

9. Rank students separately inside each city.

10. Find students whose marks are above the overall average.

11. Create a view called toppers for marks >= 80.

12. Create an index on city.

13. Create a procedure to get a student by ID.

14. Create a function that returns grade.

15. Create an audit trigger for DELETE.

16. Write a transaction and demonstrate ROLLBACK.

17. Write a CTE to find above-average students.

18. Use LAG to show the previous student's marks.

19. Use LEAD to show the next student's marks.

20. Calculate a running total of marks.
