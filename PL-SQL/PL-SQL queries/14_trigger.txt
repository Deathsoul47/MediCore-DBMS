SQL PART 14 — TRIGGERS
=======================

A trigger runs automatically when an INSERT, UPDATE or DELETE
event occurs.

1. Audit table:

CREATE TABLE student_audit (
    audit_id INT AUTO_INCREMENT PRIMARY KEY,
    student_id INT,
    student_name VARCHAR(50),
    action_type VARCHAR(20),
    action_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

2. AFTER DELETE trigger:

DELIMITER //

CREATE TRIGGER after_student_delete
AFTER DELETE
ON students
FOR EACH ROW
BEGIN
    INSERT INTO student_audit
    (student_id, student_name, action_type)
    VALUES
    (OLD.student_id, OLD.name, 'DELETE');
END //

DELIMITER ;

3. Test:

DELETE FROM students
WHERE student_id = 2;

SELECT *
FROM student_audit;

OUTPUT:
student_id = 2
student_name = Aman
action_type = DELETE

OLD = value before the operation.
NEW = new value during INSERT/UPDATE.

4. BEFORE INSERT trigger:

DELIMITER //

CREATE TRIGGER before_student_insert
BEFORE INSERT
ON students
FOR EACH ROW
BEGIN
    IF NEW.marks < 0 THEN
        SET NEW.marks = 0;
    END IF;

    IF NEW.marks > 100 THEN
        SET NEW.marks = 100;
    END IF;
END //

DELIMITER ;

If marks = 120 is inserted, it becomes 100.
