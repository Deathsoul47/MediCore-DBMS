SQL PART 11 — INDEXES
======================

Indexes help databases find rows faster.

1. Create index:

CREATE INDEX idx_student_name
ON students(name);

2. City index:

CREATE INDEX idx_student_city
ON students(city);

3. Show indexes:

SHOW INDEX FROM students;

4. Drop index:

DROP INDEX idx_student_name
ON students;

IMPORTANT:
Indexes can improve SELECT performance but consume
storage and can add overhead to INSERT, UPDATE and DELETE.

Do not blindly index every column.
