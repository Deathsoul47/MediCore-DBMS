47. SQL EXECUTION ORDER
============================================================

For a normal SELECT query, remember this conceptual order:

FROM
JOIN
WHERE
GROUP BY
HAVING
SELECT
DISTINCT
ORDER BY
LIMIT


============================================================
48. DELETE vs TRUNCATE vs DROP
============================================================

DELETE:
Removes selected rows.
Table remains.

TRUNCATE:
Removes all rows.
Table structure remains.

DROP TABLE:
Removes the entire table, including structure.


============================================================
49. QUICK INTERVIEW OUTPUT CONCEPTS
============================================================

WHERE:
Filters individual rows.

HAVING:
Filters groups after GROUP BY.

INNER JOIN:
Only matching rows.

LEFT JOIN:
All left rows + matching right rows.

RIGHT JOIN:
All right rows + matching left rows.

UNION:
Combines results and removes duplicates.

UNION ALL:
Combines results and keeps duplicates.

ROW_NUMBER:
Unique sequential number.

RANK:
Same rank for ties, gaps after ties.

DENSE_RANK:
Same rank for ties, no gaps.

LAG:
Previous row's value.

LEAD:
Next row's value.

PARTITION BY:
Creates independent groups for window calculations.

CTE:
Named temporary query result.

VIEW:
Saved virtual query/table.

TRIGGER:
Automatically executes on an INSERT/UPDATE/DELETE event.

TRANSACTION:
Use COMMIT to save and ROLLBACK to undo.
